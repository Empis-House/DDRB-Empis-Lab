# Mario RL – Sprite Assets

## Populating this folder automatically

Run the helper script from the repo root:

```
python tools/download_smb_sprites.py
```

It downloads the sprite sheet used by the open-source
[marblexu/PythonSuperMario](https://github.com/marblexu/PythonSuperMario)
project, extracts every needed sprite, and saves them here.
